====================================================
ProofChain — Firestore Security Rules
====================================================

These rules are published in the Firebase Console:
  Console → Firestore Database → Rules tab

What they do:
  - Only the signed-in user can read/write their own data
  - Anonymous users are denied all access
  - Cross-user access is blocked (user A cannot read user B's data)

====================================================
RULES
====================================================

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Only the signed-in user can read/write their own profile
    match /users/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }

    // Deny everything else by default
    match /{document=**} {
      allow read, write: if false;
    }

  }
}

====================================================
DATA STRUCTURE
====================================================

Firestore collection: users
  Document ID: <Firebase Auth UID>
  Fields:
    student: {
      id, name, email, course, goal, createdAt
    }
    skills: [ { id, name, category, selfLevel, relatedSkills } ]
    evidence: [ { id, skillId, type, title, description, link, dateCompleted, verified } ]
    assessments: [ { id, skillId, score, dateTaken, questionsAttempted } ]
